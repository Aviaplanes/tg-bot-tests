# Формы вывода Telegram-бота

[English version →](README.en.md)

Rust-библиотека и бот с 22 сценариями вывода ответов модели и вызовов инструментов: нативный стриминг черновиков, статические сообщения, карточки инструментов и сворачивание длинного текста. Каждый сценарий — отдельная команда и отдельный модуль.

## Стек

- Rust 2024, rustc ≥ 1.99
- teloxide-fork 0.18 (Bot API 10.3)
- Методы Bot API 9.3–10.3 вызываются напрямую через HTTP, без ожидания обёрток в библиотеке
- reqwest, serde_json, tokio, dptree

## Запуск

```bash
cp .env.example .env
# укажите TELOXIDE_TOKEN
cargo run --release -p tg-lab-bot
```

Отправьте боту `/help`, чтобы получить список команд. `.env` загружается автоматически.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TELOXIDE_TOKEN` | — | токен от @BotFather |

## Сценарии

### Стриминг ответов

| Команда | Что видно в чате |
|---|---|
| `/native_stream` | Ответ появляется по буквам, без пометки «изменено» |
| `/stream_stop` | Кнопка «Стоп»; уже написанный кусок сохраняется |
| `/edit_stream` | То же через редактирование — работает в группах |
| `/rich_stream` | Ответ с заголовками и блоком «Подробности» появляется постепенно |
| `/stream_long` | Длинный ответ продолжается следующими сообщениями |
| `/stream_heartbeat` | Пока инструмент думает, превью не исчезает |
| `/stream_fallback` | Режим выбирается автоматически под возможности чата |

### Статика и инструменты

| Команда | Что видно в чате |
|---|---|
| `/static_answer` | Обычный ответ одним сообщением |
| `/tool_static` | Карточки действий: что запустили и что получилось |
| `/tool_progress` | Одна карточка меняет статус: очередь → работа → готово |
| `/tool_stream` | Параметры инструмента набираются по частям, результат — карточкой |
| `/mix_turn` | Полный ход: карточки, живой ответ, источники |
| `/tool_thread` | Технические логи убраны в отдельную ветку |
| `/tool_actions` | Индикаторы «печатает…» / «отправляет файл» |
| `/tool_error` | Понятная карточка ошибки и кнопка «Повторить» |

### Сворачивание текста

| Команда | Что видно в чате |
|---|---|
| `/expand_html` | Длинный текст под «Показать ещё» |
| `/expand_md` | То же в MarkdownV2 |
| `/expand_keyboard` | Разворачивание по кнопке, работает везде |
| `/expand_spoiler` | Скрытый текст открывается касанием |
| `/expand_rich` | Нативный блок со стрелкой внутри сообщения |
| `/expand_pages` | Очень длинный отчёт листается страницами |
| `/expand_summary` | Сначала главное, подробности по желанию, кнопка копирования |

## Архитектура

```
crates/tg-lab-core/   транспорт Bot API, стриминг, карточки, сворачивание, тесты
crates/tg-lab-bot/    dispatcher, обработчики, 22 модуля сценариев
```

`tg-lab-core` не зависит от teloxide и подключается к любому проекту. Отправка идёт через `Api` с вызовом метода по имени; teloxide отвечает за получение обновлений, команды, callback-кнопки и `stopped_message_generation`.

## Особенности Bot API

- `sendMessageDraft` работает только в приватных чатах. Черновик эфемерный (~30 секунд), не имеет `message_id`; готовый ответ всегда отправляется отдельным сообщением.
- Если метод недоступен, `AdaptiveStream` переключается на `sendMessage` + `editMessageText` и запоминает это для чата.
- `sendRichMessageDraft` требует Bot API 10.2; `can_stop` и `stopped_message_generation` — 10.3.
- `<blockquote expandable>` и rich `<details>` поддерживаются не всеми клиентами; для полной совместимости есть вариант с инлайн-кнопкой.

## Интеграция

- Замените демонстрационный поток токенов `FakeAgent` на стрим своей модели: контракт — `push(delta)` по мере генерации, затем `finish(final_text)`.
- Состояния аккордеонов, страниц, реестр активных черновиков и кэш способностей хранятся в памяти. Для длительной работы подключите хранилище с TTL.
- Добавьте ретраи на 5xx/429, ограничение частоты запросов и метрики.
- Экранируйте текст модели и аргументы инструментов перед отправкой.
